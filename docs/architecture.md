# Architecture

State and IPC live in `services/`, tokens and scaling live in `config/`, reusable widgets live in `components/`, and visual surfaces live in `modules/`.

## Root
- `shell.qml` — Entry point (`//@ pragma UseQApplication` for tray menus). Spawns per-screen `BarWindow`, `ControlCenterWindow`, `NotificationToast`, and `OsdWindow` variants and registers all IPC handlers (`drawer`, `dnd`, `hw`, `osd`, `updates`, `test`, `log`, `theme`).
- `tests.sh` — Stress tests notifications (`./tests.sh notifs`), bar module states (`./tests.sh pills`), or both (`./tests.sh`).

## `config/`
- `Metrics.qml` — Main user-facing styling and scaling config. Holds `moduleRadius` (`-1` for pills, `>= 0` for boxes), `baseModuleGapX`, `baseModuleGapY`, `baseBarMarginX`, `baseModulePadding`, `cornerRadius`, borders, opacities, and DPI scaling (`scaleFor(screen)`, `scaled(val, scale)`).
- `Theme.qml` — Pure Material 3 color palette generated by Matugen.
- `Typography.qml` — Uses `Qt.application.font` with `JetBrainsMono NFP` fallback and exposes `size()`, `sizeSmall()`, and `sizeLarge()`.
- `Commands.qml` — Centralizes external app commands (`terminal`, `mixer`, `netManager`) and `Qt.resolvedUrl`-resolved script paths.

## `services/`
- `Logger.qml` — Leveled logger (`error`, `warn`, `info`, `debug`) configured via `QUICKSHELL_LOG_LEVEL` or `quickshell ipc call log level <lvl>`.
- `CompositorAdapter.qml` — Exposes `activeWsId`, `focusMon`, `activeTop`, `activeWinTitle`, `workspaces`, `dispatchWorkspace()`, `stepWorkspace()`, `focusApp()`, and `resolveMode()`, loading the right backend from `services/backends/`.
- `services/backends/` — `HyprlandBackend.qml` (Hyprland Lua/legacy IPC) and `NiriBackend.qml` (`$NIRI_SOCKET` `EventStream` + `niri msg action`).
- `HardwareState.qml` — PipeWire sink/source volume and mute, capslock OSD, and sysfs/`brightnessctl` backlight state. IPC lives in `shell.qml` (`hw`).
- `SystemState.qml` — `UPower` battery, `Quickshell.Networking` Wi-Fi/Ethernet, and `scripts/check_updates.sh` counts. IPC lives in `shell.qml` (`test`).
- `MediaState.qml` — Picks the active MPRIS player (keeping idle sockets alive until closed, filtering out Waterfox, Discord, and social links), tracks playback progress, and runs a single shared `cava` process.
- `NotificationState.qml` — Runs `NotificationServer` (actions, action icons, images, markup/links, inline replies, persistence), manages `histModel` and `toastModel`, and tracks DND/drawer state.

## `components/`
- `IconButton.qml` — Reusable interactive glyph button for media transport controls.
- `BarModule.qml` — Base bar container reading `Metrics.moduleRadius`, `Metrics.baseModulePadding`, and `Metrics.moduleBorderWidth`, with `BarModule.Icon`, `BarModule.Label`, click/wheel signals, and scroll accumulation.
- `SliderRow.qml` — Reusable icon + track + percentage slider row used by `HardwareSliders.qml`.
- `NotificationCard.qml` — Shared toast/history card composing `NotificationHistoryTree.qml`, `NotificationActions.qml`, and `NotificationReplyBar.qml` with per-card hover and horizontal swipe-to-dismiss.
- `MarqueeText.qml` — Scrolls text horizontally when it overflows its container.
- `SpringBehavior.qml` — Shared spring presets (`default`, `instant`, `exit`).

## `modules/`
- `modules/bar/` — `BarWindow.qml` lays out `ClockModule`, `WorkspacesModule`, `IdleModule`, `MprisModule`, `CavaModule`, `WindowTitleModule`, `UpdatesModule`, `SystemTrayModule`, `AudioModule`, `BatteryModule`, `NetworkModule`, `BacklightModule`, and `ControlCenterModule` (`PrivacyModule.qml` is also included as an optional drop-in).
- `modules/controlcenter/` — `ControlCenterWindow.qml` preloads drawer contents asynchronously and hosts `QuickToggles.qml`, `HardwareSliders.qml`, `MprisCard.qml`, and `NotificationHistory.qml`.
- `modules/notifications/` — `NotificationToast.qml` renders floating top-right banners with per-card hover pause and swipe-to-dismiss.
- `modules/osd/` — `OsdWindow.qml` renders the bottom-center volume, brightness, mic, and capslock popup.

## `scripts/`
- `check_updates.sh` — Checks Arch, AUR, and Flatpak updates in parallel with a 30-minute `/tmp` cache.
- `update.sh` — Runs `yay` and `flatpak update`, clears the cache, and triggers `quickshell ipc call updates refresh`.

## IPC Reference
- `quickshell ipc call drawer toggle|open|close`
- `quickshell ipc call dnd toggle|on|off`
- `quickshell ipc call hw volUp|volDown|volMute|briUp|briDown|micMute|capsToggle`
- `quickshell ipc call osd show '{"type":"volume","value":0.5,"icon":"󰕾","muted":false}'`
- `quickshell ipc call updates refresh`
- `quickshell ipc call test battery|wifi|ethernet|updates|reset`
- `quickshell ipc call log level error|warn|info|debug`
- `quickshell ipc call theme reload`
